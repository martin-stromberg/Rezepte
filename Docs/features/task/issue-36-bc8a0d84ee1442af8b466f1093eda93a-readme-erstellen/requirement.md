# Anforderung

## Ausgangslage

Die README des Projekts ist nur als Platzhalter vorhanden und beschreibt weder Zweck noch Betrieb des Systems.

## Ziel

Eine aussagekraeftige README soll nachgeholt werden, als waere sie im Rahmen des Lifecycle-Ablaufs entstanden.

## Abweichung vom Standard-Lifecycle

Es soll kein neues Feature implementiert werden. Stattdessen wird eine Bestandsaufnahme des bestehenden Projekts durchgefuehrt und daraus die Projektdokumentation erstellt.

## Akzeptanzkriterien

- Die README beschreibt fachlichen Zweck, Funktionsumfang und technischen Stack des Projekts.
- Die README enthaelt nachvollziehbare Hinweise zu Voraussetzungen, lokaler Ausfuehrung, Tests, Konfiguration und Deployment.
- Aussagen werden aus vorhandenen Projektdateien abgeleitet.
- Die Codebasis wird nicht veraendert.
