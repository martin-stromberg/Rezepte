# Vollständige Testliste mit Einstufung (Audit-Ausgang)

Alle Testklassen beider Testprojekte, statisch auditiert anhand der Signale aus der
Anforderung (Subprozess/`Process.Start`, Sockets/`TcpListener`, Playwright-Timeouts, feste
Sleeps/`Task.Delay`-Warten, Temp-Dateisystem, freie-Port-Vergabe, Env-Variablen, externe
Repositories). Stand: Commit `7c959cc`.

**Legende Einstufung:**
- **D** — deterministisch (In-Memory: EF InMemory / SQLite `:memory:` / Moq / bUnit / reine Logik)
- **D/T** — deterministisch, aber Temp-Dateisystem-Nutzung (`Path.GetTempPath`, `CreateTempSubdirectory`) — Cleanup-Kandidat für `TempDirectoryCleanup`
- **T** — Timing-Marge (`Task.Delay`-/Deadline-Warten; flake-anfällig unter Last)
- **U** — umgebungssensitiv (Kindprozess, echter Netzwerk-/DNS-Zugriff, Env-Variablen, externer Checkout)
- **F** — Kandidat für Fake-Umbau
