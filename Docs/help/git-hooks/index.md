# Git-Hooks

Die Git-Hooks führen automatisierte Qualitätsprüfungen vor jedem Commit und Push aus. Sie verhindern, dass unformatierter, unlokalisierter oder unzureichend dokumentierter Code in die Versionskontrolle gelangt, und sperren direkte Änderungen an `main` und `staging`.
