# CLAUDE.md

## Code Language

Program code must be written in English. This includes identifiers, comments, log messages, validation messages, and exception messages.

User-facing messages may be localized only when they are explicitly processed through a localization mechanism such as a Localizer. Exception messages and other errors that are not localized must remain in English.

## Fact-Based Work

Do not make assumptions about the state of the system, the repository, or external resources. Verify facts using the available tools before drawing conclusions or making changes. When something cannot be verified, explicitly state that it is an unverified assumption and ask instead of proceeding on a guess.
